Deep Learning

Learn neural networks, CNNs, RNNs and modern deep learning concepts through theory and practical examples.

Instructor Yogendra Jain
Phase Phase-2
Credits 3

Course Modules

Core areas covered throughout the Deep Learning course.

Artificial Neural Networks

ANN architecture, neurons, activation functions, forward propagation and training.

Convolutional Neural Networks

CNN layers, convolution, pooling, feature extraction and image classification.

RNN & LSTM

Sequential data, recurrent networks, vanishing gradients and LSTM architecture.

Deep Learning Training

Loss functions, optimizers, backpropagation, regularization and model training.

Deep Learning Syllabus

Five-unit learning roadmap designed for academic preparation, interviews and placements.

Placement Oriented
01

Unit 1 — Neural Network Foundations

ANN Fundamentals & Mathematical Basics
  • Introduction to Deep Learning
  • Artificial Neural Network architecture
  • Neurons, weights and biases
  • Activation functions
  • Forward propagation
  • Loss and cost functions
  • Gradient descent
  • Basic matrix operations for neural networks
Placement Focus: Be prepared to explain neurons, activation functions, forward propagation, loss functions and gradient descent with simple examples.
02

Unit 2 — Training & Optimization

Backpropagation, Optimization & Regularization
  • Backpropagation algorithm
  • Chain rule and gradients
  • Learning rate
  • Batch, mini-batch and stochastic gradient descent
  • Adam, RMSProp and Momentum
  • Overfitting and underfitting
  • Dropout and regularization
  • Batch normalization
Placement Focus: Understand why models overfit, how backpropagation works and how optimizers improve neural-network training.
03

Unit 3 — Convolutional Neural Networks

Computer Vision & Image Processing
  • CNN architecture
  • Convolution operation
  • Filters and feature maps
  • Stride and padding
  • Pooling layers
  • ReLU and other activations
  • CNN output-size calculations
  • Image classification
Placement Focus: Practice CNN numerical problems involving convolution output size, padding, stride, pooling and parameter calculations.
04

Unit 4 — RNN, LSTM & Sequential Learning

Sequence Modeling & Natural Language Processing
  • Sequential data and sequence modeling
  • Recurrent Neural Networks
  • Hidden states
  • Backpropagation Through Time
  • Vanishing and exploding gradients
  • LSTM architecture
  • Forget, input and output gates
  • GRU and sequence applications
Placement Focus: Know why basic RNNs struggle with long sequences and how LSTM gates help preserve important information.
05

Unit 5 — Modern Deep Learning

Transfer Learning, Deployment & Practical AI
  • Transfer learning
  • Pre-trained neural networks
  • Fine-tuning
  • Data augmentation
  • Autoencoders
  • Introduction to attention mechanisms
  • Model evaluation and error analysis
  • Deep learning model deployment concepts
Placement Focus: Understand transfer learning, fine-tuning, model evaluation and how a trained deep-learning model can be integrated into a real application.

Placement Preparation Focus

Along with theory, students should be able to solve numerical problems, explain architectures and discuss practical deep-learning scenarios during technical interviews.

Numericals

CNN output size, parameters, gradient descent and matrix operations.

Coding

Build basic ANN/CNN models using Python and TensorFlow/PyTorch concepts.

Interviews

Explain ANN vs CNN, RNN vs LSTM, overfitting, optimizers and transfer learning.
